# Employee Salary Management System

## Objective

Practice Python **Functions** and **File Handling** concepts by creating a simple employee salary management system.

## Requirements

Create a Python program that can:

1. Add employee information using functions.
2. Store employee data in a text file named `employees.txt`.
3. Read and display all employee records from the file.
4. Use reusable functions for each operation.

## Program Features

### Function 1: Add Employee

Create a function that takes the following information:

- Employee Name
- Employee ID
- Salary

The function should save the employee information into the file.

**Example:**

```text
Rahim | E101 | 25000
```

### Function 2: View Employees

Create another function that:

- Reads data from `employees.txt`.
- Displays all employee information.

## Sample Output

```text
1. Add Employee
2. View Employees
3. Exit

Choose Option: 1
Enter Name: Rahim
Enter ID: E101
Enter Salary: 25000

Employee Added Successfully
```

## Concepts You Must Use

- Functions
- Function Parameters
- Return Statement
- File Handling
- File Modes (`r`, `a`)
- Reusable Functions
